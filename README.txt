Spectres of Midwinter - Foundry Module (full package)
----------------------------------------------------

Files included in this ZIP:
- module.json (module manifest inside the module folder)
- manifest.json (the HTTP manifest Foundry uses to install by URL)
- actors/ (JSON actor templates with stat summaries sourced from the PDF)
- items/ (Krampus' Fork JSON with full text summary)
- scenes/ (scene JSON placeholders referencing maps/ placeholder images)
- maps/ (README explaining where to place your map images)
- midjourney_prompts_expanded.txt (token/portrait/scene prompts)

Important hosting/install instructions:
1) Host this ZIP at a public URL (HTTPS) and the manifest.json at a public URL (e.g., https://your-host.example/spectres-of-midwinter/manifest.json).
2) Edit manifest.json 'download' and 'manifest' fields to point to the final URLs where you host the ZIP and manifest.
3) In Foundry, Setup -> Add-on Modules -> Install Module -> Install from URL. Paste the manifest.json URL.
4) After installation, enable the module in the world configuration and import actors/items/journals as needed.
